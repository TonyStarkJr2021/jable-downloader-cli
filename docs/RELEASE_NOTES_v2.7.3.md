# v2.7.3

这是 v2.7 系列的 SupJav 广告防护与播放器可靠性更新。

## SupJav 专用广告防护

- 在 SupJav Chromium 捕获上下文中压制 `window.open`，点击事件仍会继续执行，播放器可以正常尝试加载。
- 自动关闭新弹窗，并阻止 SupJav 主播放页跳转到随机外部广告页面。
- 新增项目自维护的 `rules/supjav-adblock.json`，包含经过审核的广告域名与路径特征。
- 规则只随 GitHub 项目版本发布，不从用户服务器静默连接或下载 EasyList、AdGuard 等第三方规则。
- 规则文件缺失或格式异常时自动降级为基础弹窗与外部导航防护，不会直接中断下载任务。

## 播放与媒体保护

- M3U8、TS/M4S 分片、密钥、媒体、XHR/Fetch 和 WebSocket 播放器数据始终优先放行。
- SupJav 播放器按有限次数轮换线路并重复尝试播放，默认最多 10 次，可设置为 1–30 次。
- 捕获结果继续执行实际媒体探测；短广告、预览、空清单和失效清单不会被当作正片。
- 后台设置新增 SupJav 广告防护开关与播放尝试次数，无需重复输入后台密码。

## 安装与升级

- 新安装会将规则部署到 `/opt/jable-downloader/rules/supjav-adblock.json`。
- 一键更新会备份旧规则并安装当前版本规则，仍使用原来的 GitHub 一键更新命令。
- 更新不会覆盖 SupJav 代理、媒体目录、Web 登录账号、端口、Jellyfin 或 MetaTube 设置。
- CI、Release 工作流和发布压缩包均检查并包含广告防护模块与规则文件。

## 验证

- 新增规则格式、域名与路径匹配、媒体优先放行、随机弹窗和外部导航拦截测试。
- 新增后台设置登录、CSRF、范围校验、保存与显示回归测试。
- 使用真实 Chromium 合成广告页验证弹窗被压制，同时播放器点击逻辑仍继续执行。
- 完整 95 项自动化测试、Python 编译检查和 Shell 语法检查通过后发布。
