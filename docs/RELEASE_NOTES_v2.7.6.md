# v2.7.6

这是任务取消与 SupJav 多网络线路自动降级版本。

## 新增功能

- Web 当前任务卡片新增“取消任务”按钮，并提供二次确认，防止误操作。
- 取消操作会终止下载器及其完整子进程组；5 秒内未退出时自动强制停止。
- 进程停止后按完整番号删除本次任务的临时分片、未完成下载文件及已生成的番号目录，并清空当前任务状态和日志。
- SupJav 自动按 IPv6 直连、IPv4 直连、专用代理的顺序降级；没有 IPv6 的 VPS 会自动继续 IPv4。
- SupJav 静态请求明确选择 IP 协议族，Chromium 回退可把 SupJav 主域名映射到可用 IPv6 地址。
- IPv6 仅针对 SupJav 主站访问，播放器与 CDN 保持兼容性优先，避免只有 IPv4 的视频线路被误伤。

## 兼容性

- 一键安装和一键更新命令保持不变。
- 更新自动补充 `supjav_ipv6_first: true`，不覆盖用户已有配置。
- 现有 SupJav 专用代理继续有效，并仅在 IPv6、IPv4 直连均失败后作为最终回退。
- 保留现有媒体目录、Web 账号与端口、Jellyfin、MetaTube、代理和广告防护配置。

## 验证

- 验证取消请求需要登录会话与 CSRF 防护。
- 验证取消会停止完整进程组，并阻止错误触发 JavBus 磁链回退。
- 验证仅清理目标番号相关文件，不影响相邻番号或其他作品。
- 验证 IPv6、IPv4、专用代理顺序和 Chromium IPv6 主机映射。
- 完整 105 项自动化测试、Python 编译、JavaScript 语法与安装/更新脚本结构检查通过后发布。
