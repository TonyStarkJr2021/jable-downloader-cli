# v2.7.5

这是安装与一键更新远程获取可靠性修复版本。

## 修复内容

- Git 克隆统一设置为非交互模式，公开仓库连接异常时不会再停在用户名输入提示。
- 官方仓库 Git 克隆失败后，自动下载同一分支的 GitHub 源码压缩包并继续安装或更新。
- Git 与压缩包两种路径都会执行原有的文件完整性、版本、编译和服务验证。
- 自定义仓库克隆失败时给出明确错误并安全退出，不尝试收集或保存 GitHub 凭据。

## 兼容性

- 一键安装与一键更新命令保持不变。
- 更新保留下载目录、SupJav 代理、广告防护设置、Web 登录、端口、Jellyfin 与 MetaTube 配置。
- v2.7.4 的 SupJav 跨域 iframe 播放器修复完整保留。

## 验证

- 验证官方仓库可以在禁用交互认证的情况下获取。
- 验证 GitHub 源码压缩包可以下载、解压并包含完整项目文件。
- 完整 98 项自动化测试、Python 编译与 Shell 语法检查通过后发布。
