# v2.7.7

这是 SupJav 网络策略修正版本。

## 修复与调整

- 移除 SupJav IPv6 优先访问、AAAA 地址解析、静态请求 IP 协议强制和 Chromium 主机映射。
- SupJav 页面与播放器访问顺序简化为 VPS 直连、SupJav 专用代理，避免无可用 IPv6 时产生无意义的失败提示和额外等待。
- 保留“SupJav 视频下载也走代理”开关；启用后画质探测、本机 HLS 转发、播放清单和媒体分片继续通过同一专用代理。
- 后台代理说明、README 和 Web 预览图已经同步调整。

## 升级兼容

- 一键安装和一键更新命令保持不变。
- 新安装不再写入旧 IPv6 配置；一键更新会移除已有配置中的遗留字段。
- 保留现有 SupJav 代理地址、视频代理开关、广告防护、媒体目录、Web 登录、端口、Jellyfin 和 MetaTube 配置。

## 验证

- 验证 SupJav 按 VPS 直连、专用代理的顺序回退。
- 验证“SupJav 视频下载也走代理”配置与 Web 开关仍然存在。
- 验证安装与更新会清理旧网络字段且不覆盖其他配置。
- 完整 104 项自动化测试、Python 编译、JavaScript 语法及仓库一致性检查通过后发布。
