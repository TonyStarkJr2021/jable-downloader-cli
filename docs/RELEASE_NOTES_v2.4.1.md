# v2.4.1

## JavBus 推荐区域显示修复

- 修复升级后浏览器缓存旧版 `app.js`，造成后端已返回磁链、任务状态显示 `alternatives`，但页面不显示推荐卡片的问题。
- 页面为 CSS 与 JavaScript 静态资源附加当前应用版本；以后更新后会自动请求新资源，不需要用户手动清理缓存。
- 找到 JavBus 候选磁链后，页面自动滚动到推荐区域；第一条仍按高清中文字幕、高清、字幕、分享日期及文件大小排序后突出显示。

## 兼容性

- 不改变 JavBus 查询与排序规则。
- 不改变一键安装和一键更新命令。
- 不修改现有媒体、存储目录、账号、端口、Jellyfin、MetaTube 或外部下载工具。
