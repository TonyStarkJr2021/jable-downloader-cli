# Jable Downloader v2.0.1

根据 v2.0.0 的首次 VPS 实测反馈修复 Web 使用体验。

## 修复与改进

- 缩小首页主标题字号，避免宽屏或缩放环境下异常换行
- 任务日志每次收到新内容都会滚动到最底部，任务完成后显示最终摘要
- 首页明确说明从“已完成”列表的“查看”入口下载到本地
- “历史成品”更名为“已完成”
- 新增后台设置页面，可视化修改用户名、密码和 Web 端口
- 修改账号或端口必须验证当前密码；修改账号会撤销其他登录会话
- 修改端口前明确提示放行 VPS 防火墙和云安全组
- 自动检查新端口是否被占用，下载任务运行时禁止更换端口
- 保存新端口后自动重启 Web 服务并显示新的访问地址
