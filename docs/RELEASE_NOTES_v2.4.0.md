# v2.4.0

## 混合前缀番号

- 支持 `300MIUM-1483`、`300mium1483`、`300MIUM 1483` 与 `1PONDO-123456` 等数字、字母混合前缀。
- 前缀必须以字母结束，后缀必须是数字；继续拒绝纯数字、路径字符、命令字符和异常超长输入。
- 下载、JavBus 回退、查重、独立番号目录与旧媒体迁移工具使用一致的标准化番号。
- 已用 JavBus 实际查询验证 `300MIUM-1483` 可返回 3 条候选磁链。

## 一条命令适配有无挂载硬盘

- 所有用户继续使用完全相同的一键安装命令，无需选择“有硬盘版”或“无硬盘版”。
- `/mnt/raid_hdd` 或 `/mnt/raid_hdd/AV` 是真实挂载点时，数据根目录使用 `/mnt/raid_hdd/AV`。
- 未检测到挂载硬盘时，自动使用 VPS 系统盘 `/var/lib/jable-downloader-data`，并在安装结果中提示实际路径和容量风险。
- 明确传入 `--data-root` 或 `JABLE_DATA_ROOT` 时始终使用指定绝对路径。
- 现有部署升级时保留配置中的原目录，不移动或删除现有媒体。

## 兼容性

- Web 文案改为通用的“服务器存储”，不再假设每台 VPS 都配置 RAID。
- Jellyfin、MetaTube、Docker、qBittorrent、挂载点、防火墙和外部 `update-media` 命令均不修改。
- 无论自动选择哪种存储，仍使用 `media/JAV/番号` 与 `media/FC2/番号` 独立目录结构。
