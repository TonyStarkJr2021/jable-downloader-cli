# v2.5.0

## 当前任务会话

- 新打开 Web 页面时，已结束任务的番号、状态、进度和日志不再回放，页面从空闲状态开始。
- 页面打开时若服务器仍有正在运行或正在搜索磁链的任务，会自动接管并继续显示；任务在当前页面结束后仍可查看本次结果。

## 已完成列表管理

- “已完成”区域新增独立管理模式，平时不占用列表空间；进入管理后支持单选、全选和批量操作。
- “仅从列表移除”会保留服务器视频，并将隐藏记录持久化到 `/var/lib/jable-downloader/hidden-media.json`。
- “删除任务及文件”会永久删除选中视频；标准独立番号目录会同时删除其中的海报、NFO 等配套文件，旧版平铺结构只删除选中的视频。
- 两种操作都要求登录会话与 CSRF 校验；所有文件路径在删除前必须解析到配置的媒体根目录内。
- 单次操作限制为 1–200 项，并在执行前验证全部目标，降低误操作与部分删除风险。

## 界面调整

- 服务器媒体库计数单位由“个成品”改为“部作品”。
- 媒体库数量继续统计服务器实际存在的视频；仅从列表移除不会让实际文件数量产生误导性变化。

## 兼容性

- 一键安装和一键更新命令保持不变。
- 不修改现有媒体目录、账号、端口、Jellyfin、MetaTube、JavBus 或外部下载工具配置。
