# v2.7.2

这是 v2.7 系列的 SupJav 播放器捕获可靠性更新。

## SupJav 完整资源识别

- Chromium 回退不再捕获到第一条 M3U8 就立即结束。
- 在完整捕获窗口内自动轮换可用播放器线路，去重收集最多 12 条候选直链。
- 对每条候选执行实际媒体探测，短于配置阈值的广告或预览会被排除并继续检查其余候选。
- 对通过完整性检查的候选继续按分辨率、码率与时长排序，选择画质最好的完整资源。
- 当所有 SupJav 候选都是短广告、空清单或不可用资源时，输出明确原因并回退到其他可用来源。

## 下载与升级兼容

- 不改变 Jable、MissAV 和 SupJav 的并行解析结构。
- 不改变现有候选下载失败后自动尝试下一来源的逻辑。
- 不新增必填配置，继续使用现有 `supjav_min_duration_seconds` 完整时长阈值。
- 更新不会覆盖 SupJav 代理、媒体目录、Web 登录账号、端口、Jellyfin 或 MetaTube 设置。

## 验证

- 新增“高画质短广告加完整 1080p 正片”选择回归测试。
- 新增“只有短广告时拒绝 SupJav 候选”回归测试。
- 完整自动化测试数量增加至 87 项，并在 Python 编译检查及 GitHub Release 工作流通过后发布。
