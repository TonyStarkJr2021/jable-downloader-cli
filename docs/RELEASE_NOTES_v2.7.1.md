# v2.7.1

这是 v2.7 系列的交互与日志可靠性更新。

## 代理设置交互

- SupJav 代理的连接测试不再要求重复输入后台密码。
- 保存或清除 SupJav 代理也不再要求重复输入后台密码。
- 所有代理操作仍要求有效登录会话并通过 CSRF 校验。
- 登录账号和 Web 端口修改继续验证当前密码。
- 代理账号、密码以及带签名的媒体地址仍不会显示在页面状态或任务日志中。

## 长任务日志

- 修复 SupJav/FFmpeg 输出较多时，日志上限会把最早的来源解析和画质选择记录挤掉的问题。
- 新的有界日志缓冲区会固定保留任务开头和最新输出。
- 超过上限时在开头与结尾之间显示明确的省略行数，不再静默截断。
- 日志响应仍保持固定上限，避免长任务持续增加浏览器轮询负担。

## 升级兼容

- 不修改现有 SupJav 代理地址、代理凭据或“视频下载也走代理”开关。
- 不修改 Web 登录账号、密码、端口、媒体路径、Jellyfin 或 MetaTube 配置。
- 更新后无需重新填写代理，下一个任务直接使用现有配置。

## 验证

- 代理测试、保存和清除在登录加 CSRF 保护下通过回归测试。
- 未登录请求和缺少 CSRF 的请求继续被拒绝。
- 日志缓冲区在大量输出后仍保留任务开头、最新结尾与省略计数。
- 完整自动化测试、Python 编译检查及 GitHub Release 工作流通过后发布。
