# v2.7.0

本版本新增 SupJav 专用代理配置，解决部分 VPS 出口 IP 被 SupJav 拒绝、所有公开搜索入口均返回 HTTP 403 时无法解析的问题。代理完全可选，默认只用于 SupJav 页面解析，不改变其他来源与下载流量。

## 新功能

- Web 后台设置新增“SupJav 专用代理”卡片。
- 支持 HTTP、HTTPS、无需认证的 SOCKS5，以及包含用户名、密码的 HTTP(S) 代理地址。
- 支持保存、测试连接和一键清除代理。
- 默认只有 SupJav 搜索页、详情页和 Chromium 播放器捕获走代理。
- 可选让 SupJav 画质探测与 HLS 视频下载也使用同一代理。

## 安全与隐私

- 保存和测试代理前必须验证当前后台密码并通过 CSRF 检查。
- 代理地址严格限制协议、主机、端口和凭据格式，不接受路径、查询参数或片段。
- Web 页面与 API 只返回不含凭据的协议、主机和端口。
- 代理账号和密码不会写入任务日志。
- 完整代理地址仅保存在权限为 `0600` 的服务器下载配置中。
- 项目不会自动接入或推荐第三方公共代理。

## 兼容性

- 新安装与升级使用相同的一键命令。
- 更新器为旧配置补充空的 `supjav_proxy_url` 和默认关闭的 `supjav_proxy_download`。
- 不修改现有媒体目录、账号、端口、Chromium profile、Jellyfin、MetaTube、Docker、挂载点或外部 `update-media` 命令。
- 未配置代理时，Jable、MissAV、SupJav 和 JavBus 的行为与 v2.6.2 一致。

## 测试

- Python 语法检查通过。
- 代理格式、凭据遮罩、Playwright 参数、静态解析、画质探测和 HLS 转发均有自动化测试。
- Web 保存、测试、清除、密码验证及安装更新兼容性均有自动化测试。
