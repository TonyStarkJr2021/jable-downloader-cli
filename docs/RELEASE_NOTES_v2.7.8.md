# v2.7.8

这是移动端登录与页面焦点修复版本。

## 修复与调整

- 修复移动端刷新控制台或从浏览器后台恢复页面时，番号输入框被浏览器自动重新聚焦、输入法键盘随即弹出的问题。
- 移除登录页用户名输入框的自动聚焦，移动端只有在用户主动点击输入框后才会显示键盘。
- 登录令牌过期或 Cookie 不匹配时，不再返回 FastAPI 默认的白底 JSON 错误页；现在会显示正常的 UTF-8 登录页面和可读提示。
- 用户名或密码错误、登录频率受限时同样刷新登录令牌，避免移动浏览器缓存旧表单后重复进入失效状态。

## 升级兼容

- 一键安装、一键更新和卸载命令保持不变。
- 不新增配置项，不改变媒体与工作目录。
- 保留现有 Web 账号、端口、SupJav 专用代理、视频代理开关、广告防护、Jellyfin 和 MetaTube 设置。
- 控制台布局和视觉样式没有变化；README 引用的 `docs/preview.png` 与仓库根目录 `preview.png` 已核对为同一张当前界面预览图。

## 验证

- 验证登录页和控制台不会请求初始输入焦点。
- 验证登录令牌失效时返回带 UTF-8 编码的 HTML 页面并自动生成新令牌。
- 完整 106 项自动化测试、Python 编译、JavaScript 语法及仓库一致性检查通过后发布。
