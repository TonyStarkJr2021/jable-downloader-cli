# v2.7.4

这是 SupJav 正片播放器触发可靠性修复版本。

## 修复内容

- 播放器激活现在会遍历 SupJav 主页面及其跨域 iframe，不再只检查外层页面。
- 支持原生 video、JW Player、Video.js、Plyr 和常见播放按钮；没有标准控件时会点击 iframe 播放区域中心。
- 同一播放器线路会保持加载并连续接受多次点击，避免 iframe 尚未完成加载就被下一次线路切换重置。
- 多条服务器线路根据总尝试次数分组轮换，确保每条线路获得实际播放机会。
- 捕获期限会根据配置的尝试次数自动延长，并在最后一次点击后等待播放器发出 HLS 请求。

## 安全与兼容性

- SupJav 专用广告防护继续阻止弹窗和外部页面劫持。
- M3U8、媒体分片、密钥和播放器数据继续优先放行。
- 所有候选流仍会执行完整时长检测，6 秒广告、短预览、空清单和失效清单不会进入下载器。
- 一键更新保留现有代理、广告防护设置、媒体目录、Web 登录、端口、Jellyfin 与 MetaTube 配置。

## 验证

- 新增跨域 iframe 播放按钮触发测试。
- 新增 SupJav 线路保持与分组轮换测试。
- 完整 97 项自动化测试、Python 编译与 Shell 语法检查通过后发布。
